# 脱敏马 (TuominMa)

> 文档智能脱敏工具 — 本地运行，不上传任何数据

![脱敏马图标](assets/icon_512.png)

## 简介

**脱敏马**是一款面向合同、采购、招投标等业务文档的本地脱敏工具，支持自动识别并替换文档中的敏感信息。所有处理均在本地完成，文档不会上传到任何服务器。

## 功能特性

- **多格式支持**：Word(.docx) / Excel(.xlsx) / PDF / TXT
- **13 种脱敏类型**：人名、公司名、电话、邮箱、地址、身份证、银行账号、信用代码、合同编号、邮编、SWIFT、网址、自定义词条
- **三档敏感度**：保守 / 标准 / 激进
- **自定义黑白名单**：支持强制保留或强制脱敏特定词条
- **拖拽批量处理**：支持拖入多个文件批量脱敏
- **可读性自动复检**：处理后自动检测常见术语是否被误替换
- **还原功能**：支持通过映射文件还原脱敏内容

## 下载

前往 [Releases](https://github.com/你的用户名/tuominma/releases) 页面下载最新版本的 `脱敏马_V1.8.1_分发包.zip`，解压后双击 `TuominMa.exe` 即可运行，无需安装。

> 首次运行若弹出 Windows SmartScreen 提示（"未知发布者"），请点击「更多信息」→「仍要运行」。

## 使用方法

1. 双击运行 `TuominMa.exe`
2. 将文档拖入左侧文件列表，或点击「添加文档」
3. 在右侧「脱敏类型」面板勾选需要脱敏的类别
4. 选择敏感度（保守/标准/激进），点击「开始处理」
5. 处理完成后，输出文件保存在源文件旁的 `tuomin_task_*` 目录

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 添加文件 |
| Ctrl+P | 开始处理 |
| Ctrl+E | 打开输出目录 |

## 重要提醒

- 脱敏输出文档仅作为内部评审草稿，**禁止直接对外交付**
- 对外正式版本需人工把占位符 `【■■■】` 回填真实业务信息
- 本工具完全本地运行，不上传任何文档数据

## 开发构建

### 环境要求

- Python 3.10+
- Windows 10/11

### 安装依赖

```bash
pip install PySide6 openpyxl python-docx pdfplumber Pillow PyInstaller
```

### 生成图标

```bash
python make_icon.py
```

### 打包 EXE

```bash
pyinstaller --onefile --windowed --name TuominMa --icon=tuominma.ico --version-file=version_info.txt main.py
```

打包产物位于 `dist/TuominMa.exe`。
